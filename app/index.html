재질·색과 모델별 작업 기록이 .zip 하나에 담겨요. 다른 PC에서 가져오기 하면 그대로 이어져요.

도움말

사용 순서

  1. GLB 열기 — 3DAISTUDIO에서 받은 .glb를 화면에 끌어다 놓거나 ‘GLB 열기’를 누르세요. 파일은 이 PC 안에서만 처리돼요.
  2. 실제 크기 — 1번에 W·D·H(mm) 중 하나를 넣으면 나머지는 모델의 원래 비율대로 채워져요(‘원래 비율 유지’, 모양 그대로). 셋을 따로 넣으려면 그 체크를 끄세요. 이때는 모델이 그 방향으로 늘어나서 비스듬한 다리의 각도 같은 모양이 바뀌어요. 상판만 다른 크기가 필요하면 3번의 ‘크기 바꾸기’를 쓰세요. 치수선이 3D 화면에 보여요.
  3. 바꿀 부분 — 3D 화면에서 부분을 클릭하고 ‘새 그룹으로’. Shift+클릭으로 여러 개, ‘비슷한 부분도’로 다리 네 개 같은 것을 한 번에, 받침대가 붙어 있으면 ‘높이로 나누기’.
  4. 질감과 색 — 탭에서 재질을 고르고 hex 색을 여러 개 넣으면 조합마다 변형이 쌓여요. 모델의 질감이 마음에 들면 ‘원래 질감 그대로 · 색만 바꾸기’. 상판처럼 주문 사이즈가 있으면 ‘크기 바꾸기’. 결이 흐르는 방향은 ‘무늬 방향’ 슬라이더로 부분마다 1° 단위로 돌려요.
  5. 내보내기 — ‘폴더에 저장’ 또는 ‘ZIP으로 받기’. 변형마다 압축된 GLB 하나, 제품 사진, 변형 목록(CSV·JSON), 카탈로그 HTML이 만들어져요. 파일마다 검사 결과가 아래에 나와요.

마우스와 키

  • 왼쪽 드래그 회전 · 오른쪽 드래그 이동 · 휠 확대/축소 · ‘시점 처음으로’ 버튼
  • 클릭 부분 선택 · Shift+클릭 여러 개 · 빈 곳 클릭 또는 Esc 해제
  • hex 입력칸·크기 입력칸에서 Enter 추가 · 높이 입력칸에서 Enter 나누기 · F1 도움말
  • ‘원본 보기’로 바꾸기 전 모습과 번갈아 보고, ‘사진 저장’으로 지금 화면을 한 장 저장해요.

저장되는 파일

  • GLB (glTF 2.0 바이너리) — 1 단위 = 1 m 실제 크기, 바닥 가운데가 원점(0, 0, 0), Y가 위. 앞면 방향은 원본 모델 그대로예요. Khronos 3D Commerce 지침과 같은 규격이라 공간무드와 대부분의 3D 뷰어·AR에 바로 들어가요.
  • 가구는 바닥에서 10mm 떠 있게 저장돼요(내보내기의 ‘바닥에서 띄우기’에서 0~100mm로 바꿀 수 있어요). 공간의 바닥이 고르지 않거나 러그를 깔아도 다리가 묻히지 않아요. W·D·H 치수는 그대로예요.
  • 압축: EXT_meshopt_compression + KHR_mesh_quantization. 텍스처는 WebP(호환 모드는 JPG). 재질은 PBR(천 sheen, 코팅 clearcoat, 헤어라인 anisotropy 확장 포함).
  • 가장자리 다듬기 — 삼각형을 줄일 때 면의 방향(빛 받는 방향)도 함께 지켜서 유광 부분의 반사와 상판 테두리가 원본처럼 매끈해요. 새 재질을 입힌 부분은 AI가 만든 표면의 잔물결을 다듬고(진짜 모서리는 그대로), 테두리 근처에서 무늬가 조각조각 끊기지 않게 정리해요. 저장할 때마다 자동으로 돼요.
  • 부분마다 프리미티브가 따로 들어가고 그룹·재질·색이 기록되어, 이 프로그램으로 다시 열면 그대로 이어서 바꿀 수 있어요.
  • 제품 사진 PNG(투명) 또는 JPG(흰 배경), 각도·크기 선택. 변형 목록 CSV(엑셀)와 JSON(웹 서비스 등록용). 카탈로그 HTML 더블클릭으로 열고 인쇄.

검사 결과 읽는 법

  • Khronos 검사 통과 — glTF 공식 검사기(glTF Validator)에서 오류가 없다는 뜻이에요. 오류가 있으면 ✗로 표시되고 CSV·JSON에도 적혀요.
  • ⓘ 참고 — 공간무드에는 제한이 없지만 해외 마켓 기준을 넘는 경우예요: 삼각형 20만 개(아마존 가구), 15 MB(Shopify는 자동 재압축), 텍스처 4096 px 초과, WebP 텍스처(아마존은 PNG·JPG만 → 호환 모드).
  • 삼각형을 줄이려면 압축을 ‘가볍게’로, 용량을 줄이려면 ‘그대로 두는 부분의 텍스처’를 2K로 해 보세요.

자주 묻는 질문

  • 저장 버튼이 안 눌려요 — 1번에 실제 크기(W·D·H 중 하나)를 넣어야 해요.
  • 3D 화면의 비율이 다른 뷰어와 달라요 — ‘원래 비율 유지’를 켜면 원래 비율로 돌아와요. W·D·H를 셋 다 따로 넣으면 그 치수에 맞춰 모델이 늘어나요.
  • 공간무드에서 테두리가 깨져 보여요 — v1.3부터 저장할 때 가장자리를 자동으로 다듬어요. 예전 버전으로 저장한 파일은 이 버전으로 다시 저장해 주세요.
  • 다시 저장해서 올렸더니 공간무드에 안 보여요 — 예전에 올린 파일과 용량이 바이트까지 같으면 공간무드가 같은 파일로 착각할 수 있어요. v1.3.2부터는 파일마다 저장 정보(버전·시각·띄운 높이)를 적고, 같은 모델로 이 PC에서 저장한 파일끼리는 용량이 겹치지 않게 저장해요. 그 전 버전으로 만든 파일이면 이 버전으로 다시 저장해 주세요.
  • 공간무드나 다른 프로그램에서 안 열려요 — ‘호환 모드’를 켜고 다시 저장하세요 (용량은 커져요).
  • 부분이 잘 안 나뉘어요 — 2번의 ‘부분이 잘 안 나뉘었나요?’에서 민감도를 올리거나, 그 부분을 클릭하고 ‘높이로 나누기’.
  • 다른 PC에서 이어서 하고 싶어요 — ‘재질·색 관리’ → ‘내보내기 (.zip)’으로 재질·색·작업 기록을 옮기세요. 같은 GLB 파일을 열면 지난 작업이 그대로 나와요.
  • 미리보기 창에서 열면 안 돼요 — 이 HTML 파일을 내려받아 더블클릭하면 크롬·엣지에서 열려요. 인터넷은 필요 없어요.
  • 무늬 방향이 이상해요 — 사진으로 만든 재질이면 그 재질의 ‘수정’에서 ‘무늬 바로잡기’로 결을 가로로 똑바로 세우고, 3번의 ‘무늬 방향’ 슬라이더로 부분마다 돌리세요. 저장 파일에도 그대로 들어가요.
  • 색이 생각과 달라요 — hex 색은 encycolorpedia.com 코드 그대로예요. 가죽·원단은 질감 때문에 조금 어둡게 보일 수 있어요. 가장 밝은 부분이 그 색이 되도록 맞춰요.
